# n8n AI Customer Support

AI-powered customer support automation built with n8n, Ollama, Docker, PHP, and MySQL.

## 🎯 Project Goal

Build a customer support automation system that receives messages through a webhook, processes them with an AI model, stores conversation history in MySQL, and returns a JSON response.

## 🛠️ Tech Stack

- n8n
- Ollama
- Docker
- PHP
- MySQL

## 📁 Project Structure

```
docs/          Documentation
workflows/     n8n workflows
database/      Database schema and scripts
php/           PHP backend
assets/        Images and other assets
```
